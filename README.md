The repository is a personal learning workspace where I add examples and exercises as I progress.

## Getting Started

### Prerequisites

- Python installed
- Java Development Kit (JDK) compatible with your Spark version
- PySpark installed, or access to an Azure Databricks workspace

### Run PySpark Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gowsalyanagaraj/pyspark-learning.git
   ```

2. Navigate to the project directory:

   ```bash
   cd pyspark-learning
   ```

3. (Recommended) Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   On Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   On macOS or Linux:

   ```bash
   source .venv/bin/activate
   ```

4. Install PySpark:

   ```bash
   pip install pyspark
   ```

5. Open the scripts or notebooks and run the examples in your local Python environment or Databricks workspace, as applicable.
